# SSLChecker
I made this to as i wanted to have my own terminal version of a SSL Checker. pwetty cool dude 


## Installation

```bash
git clone https://github.com/yourname/ssl-checker.git

cd ssl-checker

pip install -r requirements.txt
```

Supports multiple domain scans and singular you can scan directly off a text file. 
examples
`google.com` - Single domain check
`google.com,Github.com,foobar.com` - reads multiple inputted manually by user 
`example.txt` - reads off the txt in the directory
